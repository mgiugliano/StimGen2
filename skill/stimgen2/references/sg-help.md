## sg help syntax

```
SYNTAX OF A WAVEFORM

A waveform is a sequence of segments, one per line (or separated by ';').
A segment is a duration followed by an expression:

    500ms  dc(0)
    1s     dc(300)                       # a 300 (pA, mV, ...) step
    500ms  dc(0)

Durations MUST carry a time unit (s, ms, us, ns, min). Everything after '#'
is a comment. Generators take parameters by position or by name:

    5s  sine(3, 1Hz)                      # = sine(amp=3, freq=1Hz)
    5s  sine(3, 1Hz, phase=90deg, offset=10)

Expressions combine generators sample by sample with + - * / and
parentheses, and with functions such as abs(), pos(), clip():

    5s  sine(50, 8Hz) + ou(mean=0, sd=20, tau=5ms)
    5s  (1 + 0.5*sine(1, 2Hz)) * sine(80, 40Hz)
    10s pos(ou(mean=10, sd=5, tau=3ms))

Blocks { ... } are sequences used as values; their duration is the sum of
their segments, and a generator combined with a block takes its duration:

    { 1s ramp(0, 1) ; 3s dc(1) ; 1s ramp(1, 0) } * sine(80, 8Hz)

repeat N { ... } repeats a part of the waveform:

    repeat 10 { 2ms dc(1000) ; 48ms dc(0) }

'prev' is the end value of the previous segment:

    1s dc(-50)
    2s ramp(from=prev, to=200)            # 'from' defaults to prev

'@name' before a segment labels it; the label becomes a marker in the
output. A file may start with the header line 'sg 2 waveform' or
'sg 2 stimulus' (see: sg help stimulus).
```

## sg help generators

```
PRIMITIVE GENERATORS (sg help NAME for parameters)

  dc        Constant level.
  ramp      Linear ramp from 'from' to 'to' over the segment.
  relax     Exponential relaxation: to + (from - to) exp(-u/tau).
  sine      Sinusoid: amp sin(2 pi freq u + phase) + offset.
  square    Square wave with duty cycle; its mean is offset + amp (2 duty - 1).
  saw       Sawtooth: rises during 'duty' of each period, falls during the rest.
  triangle  Symmetric triangle, the same as saw(..., duty=0.5).
  chirp     Sinusoid whose frequency sweeps from f0 to f1 over the segment (ZAP).
  biexp     Difference of exponentials normalised to peak amp (synaptic-like).
  alpha     Alpha function amp (v/tau) exp(1 - v/tau), v = u - delay.
  file      Samples read from a text file and resampled.
  pulses    Train of pulses: offset + amp * sum of kernels at the onset times.
  ou        Ornstein-Uhlenbeck process (exact update; Gaussian, exponential autocorrelation).
  wnoise    Gaussian white noise, independent samples.
  unoise    Uniform white noise with the given mean and standard deviation.
  cnoise    Gaussian noise with a power-law spectrum, synthesised over the whole segment.

Functions: sg help maps

## sg help maps

```
OPERATORS AND FUNCTIONS (applied sample by sample)

  a + b, a - b, a * b, a / b, -a      usual precedence: * / before + -
  abs(e)          |x|
  pos(e)          max(x, 0), e.g. a conductance that must stay >= 0
  sqrt(e)         square root, x >= 0
  exp(e), log(e)  exponential, natural logarithm (x > 0)
  pow(e, k)       x^k  (x >= 0 unless k is an integer)
  spow(e, k)      sign(x) |x|^k, defined for every x
  clip(e, lo, hi) limit to [lo, hi]
  min(a, b), max(a, b)

Combined waveforms with their own durations (blocks) must have the same
duration. A value that is not finite (division by zero, sqrt of a
negative number, ...) stops the program with an error that names the
line and the sample: a stimulus is never altered silently.
```

## sg help units

```
UNITS (a number followed immediately by a unit, e.g. 500ms, 20kHz)

  time         s ms us (or µs) ns min    canonical: s
  frequency    Hz kHz MHz                canonical: Hz
  phase        rad deg                   canonical: rad
  fraction     %                         50% = 0.5
  current      fA pA nA uA mA A
  voltage      uV mV V
  conductance  pS nS uS mS S

A number without unit is in the canonical unit of its parameter, except
segment durations, which must always carry a unit. Amplitudes without a
unit are in the unit of the channel; with a unit (e.g. dc(0.3nA) on a
channel in pA) they are converted, and a wrong kind of unit is an error.
Units are case-sensitive: ms is a millisecond, mS a millisiemens.
```

## sg help stimulus

```
STIMULI: SEVERAL CHANNELS ON ONE TIME BASE

    sg 2 stimulus
    rate 20kHz                  # optional; else give -r
    seed 4711                   # optional master seed

    channel pre unit=pA rest=0 {
        1s     dc(0)
        @train                  # marker 'pre.train' at the next segment
        500ms  pulses(amp=2000, rate=20Hz, width=1ms)
        1s     dc(0)
    }
    channel post unit=pA { 2.5s dc(-50) }
    channel copy1 unit=pA copy pre        # identical samples, noise included
    channel B unit=pA use "noise.sg"      # waveform from a file
    digital camera { 1s dc(0); 1.5s pulses(1, 100Hz, width=1ms) }
    marker flash at 1s, 1.5s
    duration 3s                 # optional; default: longest channel

Channels shorter than the stimulus hold their rest value. Digital channels
must contain only 0 and 1. A plain waveform file is a stimulus with one
channel named 'out' (unit from -u).
```

## sg help noise

```
NOISE, SEEDS AND REPRODUCIBILITY

Every stochastic generator (ou, wnoise, unoise, cnoise, Poisson pulses)
draws from its own random stream. The stream is keyed by SHA-256 of

    "<master seed>:<address>"   e.g. "42:ch=out/s1/o1"

where the address is the position of the generator in the description,
or by "fixed:<n>" when the generator has seed=n. The stream itself is
Philox4x64-10 (a counter-based generator); uniform, Gaussian (Box-Muller)
and exponential variates are derived from it exactly as the
specification prescribes. Consequences:

  - the same description, rate and master seed give the same samples on
    every machine (Level B: equal up to the last bits of sin/exp/log);
  - changing one segment does not change the noise of the others;
  - seed=n gives the same realisation wherever it is used (frozen noise);
  - the master seed actually used is always written to the output.

'sg selftest' checks SHA-256 and Philox against published test vectors.
```

## sg help protocol

```
PROTOCOLS: REPETITIONS, SWEEPS, ORDER, TIMING

    sg 2 protocol
    sweep  amp = from -300pA to 300pA step 50pA    # or [10pA, 20pA], linspace(a,b,n)
    sweep  (amp, dur) = [(100pA, 1s), (200pA, 500ms)]   # values that go together
    let    q = amp * dur                           # derived variable
    repeat 3                                       # repetitions of each condition
    order  shuffled-blocks     # sequential | grouped | shuffled | shuffled-blocks
    period 5s                  # onset to onset; or: gap 2s (pause between trials)
    noise  per-trial           # per-trial | per-condition (frozen) | fixed
    seed   2026                # protocol seed; -s overrides it
    start  immediately         # or: on trigger

    stimulus {                 # or: stimulus "file.sg"
        channel Iinj unit=pA {
            500ms dc(0)
            1s    dc($amp)                         # $name, or $( expression )
            500ms dc(0)
        }
    }

Several sweeps combine as a Cartesian product (the first varies slowest).
Substitution is textual, before the stimulus is parsed. Each trial gets
a master seed derived from the protocol seed (SHA-256 of 'trial:s:j',
'condition:s:c' or 'fixed:s'); random orders use Fisher-Yates on the
stream 'order:s'.

  sg render steps.sg               one .sgb per trial in steps_sgb/
  sg expand steps.sg steps/        steps/0000.sg ... and steps/protocol.sgi
  sg render steps/                 the same trials, samples and seeds

Timing (period, gap, trigger) is recorded in every trial's provenance and
in protocol.sgi; sg renders trials, it does not play them in real time.
```

## sg help output

```
THE .sgb FILE

  bytes 0-7    'S' 'G' 'B' and five zero bytes
  bytes 8-15   length L of the header, unsigned 64-bit, little-endian
  next L       JSON header (UTF-8), padded with spaces: 16 + L is a
               multiple of 8, so the samples are 8-byte aligned
  rest         samples: 64-bit IEEE doubles, little-endian, all samples of
               channel 1, then channel 2, ... (the order of 'channels')

The JSON header holds: version, rate, samples (per channel), channels
(name, unit, rest, digital), markers (name, sample index), and the
provenance record: the full description text, the SHA-256 of its
canonical form, data files used and their SHA-256, the rate, the master
seed (as a string), the SHA-256 of the sample bytes, warnings and a time
stamp. From description, rate and seed the samples can be regenerated.

Reading it in Python:
    import json, numpy as np
    b = open('x.sgb', 'rb').read()
    L = int.from_bytes(b[8:16], 'little')
    h = json.loads(b[16:16+L])
    x = np.frombuffer(b[16+L:], '<f8').reshape(len(h['channels']), -1)
```

## Generators, one by one

### ramp

```
ramp: Linear ramp from 'from' to 'to' over the segment.
  (duration-aware)
  parameters, in positional order:
    from       amplitude  default prev       start value (default: prev, the end value of the previous segment)

### relax

```
relax: Exponential relaxation: to + (from - to) exp(-u/tau).
  parameters, in positional order:
    from       amplitude  default prev       start value (default: prev)
    to         amplitude  required           asymptotic value
    tau        time       required           time constant (> 0)
```

### sine

```
sine: Sinusoid: amp sin(2 pi freq u + phase) + offset.
  parameters, in positional order:
    amp        amplitude  required           amplitude (half of peak-to-peak)
    freq       frequency  required           frequency (>= 0)
    phase      phase      default 0          phase at u = 0 (rad, or deg)
    offset     amplitude  default 0          constant added to the waveform
    clock      keyword    default local      local: time restarts in each segment; global: time from the start of the waveform
                                             one of: local|global
```

### square

```
square: Square wave with duty cycle; its mean is offset + amp (2 duty - 1).
  parameters, in positional order:
    amp        amplitude  required           the wave alternates between offset +/- amp
    freq       frequency  required           frequency (> 0)
    duty       fraction   default 0.5        fraction of the period at the high level, 0..1 (or %)
    phase      phase      default 0          phase at u = 0 (rad, or deg)
    offset     amplitude  default 0          constant added to the waveform
    clock      keyword    default local      local: time restarts in each segment; global: time from the start of the waveform
                                             one of: local|global
```

### saw

```
saw: Sawtooth: rises during 'duty' of each period, falls during the rest.
  parameters, in positional order:
    amp        amplitude  required           the wave spans offset - amp .. offset + amp
    freq       frequency  required           frequency (> 0)
    duty       fraction   default 1          fraction of the period spent rising (1: rising saw, 0.5: triangle)
    phase      phase      default 0          phase at u = 0 (rad, or deg)
    offset     amplitude  default 0          constant added to the waveform
    clock      keyword    default local      local: time restarts in each segment; global: time from the start of the waveform
                                             one of: local|global
```

### triangle

```
triangle: Symmetric triangle, the same as saw(..., duty=0.5).
  parameters, in positional order:
    amp        amplitude  required           the wave spans offset - amp .. offset + amp
    freq       frequency  required           frequency (> 0)
    phase      phase      default 0          phase at u = 0 (rad, or deg)
    offset     amplitude  default 0          constant added to the waveform
    clock      keyword    default local      local: time restarts in each segment; global: time from the start of the waveform
                                             one of: local|global

### chirp

```
chirp: Sinusoid whose frequency sweeps from f0 to f1 over the segment (ZAP).
  (duration-aware)
  parameters, in positional order:
    amp        amplitude  required           amplitude
    f0         frequency  required           frequency at the start of the segment
    f1         frequency  required           frequency at the end of the segment
    law        keyword    default linear     linear or exponential (equal time per octave) sweep
                                             one of: linear|exp
    phase      phase      default 0          phase at u = 0 (rad, or deg)
    offset     amplitude  default 0          constant added to the waveform

### biexp

```
biexp: Difference of exponentials normalised to peak amp (synaptic-like).
  parameters, in positional order:
    amp        amplitude  required           peak value above offset
    tau_rise   time       required           rise time constant (> 0)
    tau_decay  time       required           decay time constant (> tau_rise)
    delay      time       default 0          onset time within the segment
    offset     amplitude  default 0          constant added to the waveform
```

### alpha

```
alpha: Alpha function amp (v/tau) exp(1 - v/tau), v = u - delay.
  parameters, in positional order:
    amp        amplitude  required           peak value above offset
    tau        time       required           time to peak (> 0)
    delay      time       default 0          onset time within the segment
    offset     amplitude  default 0          constant added to the waveform
```

### file

```
file: Samples read from a text file and resampled.
  parameters, in positional order:
    path       string     required           text file, one sample per row
    rate       frequency  required           sampling rate of the file
    column     number     default 1          column to read (1 = first)
    interp     keyword    default hold       hold the last sample, or interpolate linearly
                                             one of: hold|linear
    extend     keyword    default error      what to do after the last sample
                                             one of: error|hold|zero|cycle
```

### pulses

```
pulses: Train of pulses: offset + amp * sum of kernels at the onset times.
  parameters, in positional order:
    amp        amplitude  required           pulse amplitude (peak of the kernel)
    rate       frequency  optional           pulse rate (required unless times is given)
    shape      keyword    default square     kernel shape
                                             one of: square|biphasic|exp|alpha|biexp
    width      time       optional           pulse width (square), width of each phase (biphasic)
    tau        time       optional           time constant (exp, alpha)
    tau_rise   time       optional           rise time constant (biexp)
    tau_decay  time       optional           decay time constant (biexp)
    timing     keyword    default regular    regular, or Poisson (random) onsets
                                             one of: regular|poisson
    times      times      optional           explicit onset times, e.g. [10ms, 25ms]
    delay      time       default 0          time of the first regular onset (or offset of all onsets)
    dead       time       default 0          dead time after each Poisson onset (< 1/rate)
    align      keyword    default grid       grid: onsets and widths rounded to samples, identical pulses
                                             one of: grid|exact
    offset     amplitude  default 0          constant added to the waveform
    seed       integer    optional           fixed seed: the same realisation wherever it is used (frozen noise)
```

    tau        time       required           correlation time (> 0)
    init       amplitude  default stationary first sample: stationary draw, the mean, prev, or a value
                                             one of: stationary|mean|prev

## sg examples

```
EXAMPLES  (indented lines are shell commands: copy, paste, run; the lines
between <<'END' and END are the content of a file and go with them)

1. A FIRST STIMULUS: a 1 s step of 300 pA, between two 500 ms pauses
  sg render -r 20kHz -e '500ms dc(0); 1s dc(300); 500ms dc(0)' -o step.sgb
  sg render -r 20kHz -u pA -e '500ms dc(0); 1s dc(0.3nA); 500ms dc(0)' -o step.sgb
  sg render -r 1kHz -t -o - -e '5ms dc(0); 5ms dc(1)'     # print the samples

2. ONE LINE PER GENERATOR (sg help generators, sg help NAME)
  sg render -r 20kHz -e '2s ramp(from=0, to=500)' -o ramp.sgb
  sg render -r 20kHz -e '5s sine(amp=50, freq=8Hz)' -o sine.sgb
  sg render -r 20kHz -e '5s square(amp=100, freq=2Hz, duty=25%)' -o square.sgb
  sg render -r 20kHz -e '5s triangle(amp=100, freq=1Hz)' -o triangle.sgb
  sg render -r 20kHz -e '10s chirp(amp=50, f0=0.5Hz, f1=20Hz)' -o zap.sgb
  sg render -r 20kHz -e '200ms biexp(amp=30, tau_rise=1ms, tau_decay=8ms)' -o epsc.sgb
  sg render -r 20kHz -e '500ms relax(from=0, to=1, tau=50ms)' -o charge.sgb
  sg render -r 20kHz -e '1s pulses(amp=2000, rate=20Hz, width=1ms)' -o train.sgb
  sg render -r 20kHz -e '1s pulses(100, 10Hz, width=0.2ms, shape=biphasic)' -o bi.sgb

3. NOISE: new, repeatable, frozen
  sg render -r 20kHz -e '10s ou(mean=100, sd=50, tau=5ms)' -o noise.sgb   # new each time
  sg render -r 20kHz -s 42 -e '10s ou(100, 50, 5ms)' -o noise42.sgb      # same with -s 42
  sg render -r 20kHz -e '10s ou(100, 50, 5ms, seed=17)' -o frozen.sgb    # always the same
  sg render -r 20kHz -e '5s wnoise(0, 10)' -o white.sgb
  sg render -r 20kHz -e '20s cnoise(0, 20, alpha=1)' -o pink.sgb
  sg render -r 20kHz -e '2s pulses(1, 10Hz, width=1ms, timing=poisson)' -o poisson.sgb

4. COMBINING AND TRANSFORMING
  sg render -r 20kHz -e '5s sine(50, 8Hz) + ou(0, 20, 5ms)' -o mix.sgb
  sg render -r 20kHz -e '5s (1 + 0.5*sine(1, 2Hz)) * sine(80, 40Hz)' -o am.sgb
  sg render -r 20kHz -e '{1s ramp(0,1); 3s dc(1); 1s ramp(1,0)} * sine(80, 8Hz)' -o env.sgb
  sg render -r 20kHz -e '10s pos(ou(10, 5, 3ms))' -o conductance.sgb
  sg render -r 20kHz -e '5s abs(sine(4, 1Hz))' -o rectified.sgb
  sg render -r 20kHz -e '1s dc(0); repeat 10 {2ms dc(1000); 48ms dc(0)}; 1s dc(0)' -o ten.sgb
  sg render -r 20kHz -e '1s dc(-50); 2s ramp(to=200); 1s ramp(to=0)' -o ramps.sgb

5. WORKING WITH FILES
  printf '500ms dc(0)\n1s dc(300)\n500ms dc(0)\n' > step.sg
  sg check step.sg                         # syntax, units, durations
  sg canon step.sg                         # the canonical form
  sg render -r 20kHz -u pA step.sg         # writes step.sgb
  sg render -r 20kHz -t step.sg            # writes step.txt (a table)

6. SEVERAL CHANNELS, MARKERS, A CAMERA TRIGGER
  cat > pair.sg <<'END'
sg 2 stimulus
rate 20kHz
channel pre  unit=pA { 1s dc(0); @train 500ms pulses(2000, 20Hz, width=1ms); 1s dc(0) }
channel post unit=pA { 2.5s dc(-50) }
digital cam  { 2.5s pulses(1, 50Hz, width=1ms) }
END
  sg render pair.sg                        # rate from the file; writes pair.sgb

7. PROTOCOLS: a family of steps, 3 times each, shuffled, one every 5 s
  cat > steps.sg <<'END'
sg 2 protocol
sweep  amp = from -300pA to 300pA step 50pA
repeat 3
order  shuffled-blocks
period 5s
stimulus { channel Iinj unit=pA { 500ms dc(0); 1s dc($amp); 500ms dc(0) } }
END
  sg check steps.sg                        # 39 trials
  sg render -r 20kHz -s 1 steps.sg         # steps_sgb/0000.sgb ... 0038.sgb
  sg expand -s 1 steps.sg steps            # steps/0000.sg ... and steps/protocol.sgi
  sg render -r 20kHz -o steps_again steps  # the same 39 trials, from the directory

8. IN SCRIPTS
  for a in 100 200 300; do sg render -q -r 20kHz -e "1s dc($a)" -o step_$a.sgb; done
  sg check step.sg > /dev/null && echo 'step.sg is valid'
  sg render -q -r 1kHz -t -o - -e '10ms sine(1, 100Hz)' | head -4

Look at any .sgb file with:  python3 tools/sgplot.py FILE.sgb
```
